Projects
Things I've Built
Each of these projects was built to solve a real problem — from legal accessibility to classical dance, AI to digital legacy.
01 / 04
Social Deduction · AI Game
Who Is The Imposter?
A multiplayer AI interrogation game where players question four AI suspects — one secretly guilty — to identify the imposter. Each character has a unique personality and responds dynamically to any question.
Gemini API JavaScript Multiplayer
02 / 04
Computer Vision · Dance Tech
Araimandi Posture Corrector
A real-time posture correction tool using MediaPipe to detect and score the Araimandi stance — the foundational half-sit position in Bharatanatyam. Built to help dancers perfect their form using AI.
MediaPipe Python Computer Vision
03 / 04
Legal AI · Practice Tool
Lawyer AI
An AI-powered tool that helps lawyers prepare and practice cases by simulating arguments, analysing case details, and providing legal insights — built during an internship at a law firm.
AI Legal Tech JavaScript
04 / 04
Digital Legacy · Privacy
Digital Executor
A tool that helps individuals identify and delete old unwanted digital files and organise their online accounts and assets — ensuring loved ones aren't left navigating the digital world alone.
JavaScript Privacy Digital Legacy
